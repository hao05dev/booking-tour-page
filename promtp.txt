Bạn là một Senior UI/UX Designer và Frontend Prototype Developer.

Tôi đang xây dựng một Website Booking Tour và hiện tại tôi CHỈ cần thiết kế giao diện và prototype để trình bày, chưa cần backend và chưa cần kết nối API.

Hãy xây dựng một prototype website Booking Tour bằng:

- HTML5
- CSS3
- JavaScript thuần nếu cần cho các tương tác đơn giản

KHÔNG sử dụng:
- React
- Next.js
- Vue
- Tailwind
- Backend
- Database
- API

Mục tiêu là tạo giao diện đẹp, hiện đại, responsive và có thể chạy trực tiếp bằng cách mở file HTML trên trình duyệt.

Không cần xử lý nghiệp vụ thật.
Chỉ cần mô phỏng UI/UX và các interaction cơ bản.
